 2. Write a MongoDB query to count number of customers in each city. 
 
 
 INVOICE> db.customer.aggregate([{$group:{_id:"$city",count:{$sum:1}}}])
[ { _id: 'kozhikode', count: 1 }, { _id: 'kochi', count: 1 } ]



 3. Write a MongoDB query to find minimum and maximum age in each city. 
 INVOICE> db.customer.aggregate([{$group: { _id: "$city",minage:{ $min:"$age"},maxage:{$max:"$age"}}}]) 
[
  { _id: 'kochi', minage: 22, maxage: 25 },
  { _id: 'kozhikode', minage: 28, maxage: 30 }
]

5. Write a query using $lookup to join CUSTOMER and PRODUCT collections and display only

customer name, product name, and price.
INVOICE> db.customer.aggregate([{ $lookup: {from: "product",localField: "pro_id",foreignField: "pro_id",as: "product_info"}},{$unwind: "$product_info"},{$project: {_id: 0,customer_name: "$name",product_name: "$product_info.name",price: "$product_info.price"}}])
[
  { customer_name: 'arun', product_name: 'laptop', price: 50000 },
